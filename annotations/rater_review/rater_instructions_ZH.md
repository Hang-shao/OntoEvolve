# 告警复核评分说明（中文版）

感谢帮忙。这份说明写清了要判什么、怎么填、不要做什么。85 行大约 2–3 小时，可以分两次做。
若说明里有不清楚的地方，请**开始评分之前**问发件人，不要就某一条记录来问。

---

## 一、你在评什么

该研究处理按批到达的文本流，边流边建本体（概念 + 带类型的公理）。检测器认为某个概念发生了
下列三类变化之一时，就会发出**告警**：

| 告警类型 | 系统的主张 |
|---|---|
| `emergence`（涌现） | 第 `t` 批**新出现**了一个概念，列出的文本条目是它的首批成员 |
| `extinction`（淘汰） | 一个已存在的概念**不再出现** |
| `redefinition`（重定义） | 概念还在用，但**含义或结构变了** |

你的任务每行只有一个问题：**所引的证据是否支持系统所说的这个主张？**

不需要评价该不该报警、阈值合不合适、本体建得好不好，只看这条告警按其所声称的内容是否有据。

## 二、表里有什么

共 85 行，你只填三列：

| 列 | 含义 |
|---|---|
| `label` | 判定：`真漂移` / `误报` / `无法判断`（也可写 `true drift` / `false alarm` / `undecidable`） |
| `confidence` | 对该判定的把握：`高` / `中` / `低` |
| `note` | 可选，一行理由（中英文皆可）。判定很明显时可留空 |

背景列仅供参考：

| 列 | 含义 |
|---|---|
| `seq` | 你这份表的行号。两位标注者的行序不同，**不要重新排序** |
| `alarm_id` | 稳定编号。讨论条目请用它，不要用 `seq` |
| `track` | `PMC` = 生物医学摘要（1997–2001）；`ICEWS18` = 编码后的政治事件记录 |
| `t` | 发出告警的批次号 |
| `dtype` | 上面三类之一 |
| `concept` | 涉及的概念。PMC 轨道是匿名内部标签（如 `topic_NEW905`），因为研究不公开聚类命名；ICEWS18 是事件谓词（如 `Make an appeal or request`）。**标签不可读只说明“无法用先验知识判断”，不代表可疑** |
| `n_members` | 该批系统归到该概念下的条目数 |
| `last_seen_t` | 该概念此前最后出现的批次（可能为空） |
| `evidence` | 系统所依据的原文引句，句子之间用换行分隔。PMC 是摘要句；ICEWS18 是 *主体—谓词—客体* 的事件记录 |

有 **4 行没有任何证据**。这是告警类型本身的性质，不是表格出错：这些行的预期答案是 `无法判断`，
除非其他列已足以定论。

## 三、判定规则

按字面执行；两条规则冲突时，序号小的优先。

### `emergence` —— 是不是真的“新的一类”？

1. **`真漂移`**：引句描述的是一个成体系的**类型级**实体、过程、关系或属性，文本自身把它当作
   一种独立的类来写，而不只是普通范畴的又一个实例。（只凭本行引句判断，不需要知道本体里已有什么。）
2. **`误报`**：引句属于以下之一——(a) 单个实例的数据点或测量值；(b) 图/表题注、方法学套话、
   操作步骤；(c) 对文本中本来就当作普通范畴的内容的复述；(d) 分词/切句伪影，引句不指向任何东西；
   (e) 同一普通事件换个说法反复出现。
3. **`无法判断`**：引句过短或过碎，无法归类；或 `n_members` 为 1 且这句可以两读。

### `extinction` —— “消失”是否有据？

1. **`真漂移`**：引句显示该实体或类型被撤回、改名、被取代、被撤稿，或明确终止。
2. **`误报`**：引句是一次普通提及（说明它还在用），或该概念是泛化类别、“停止出现”对它无意义。
3. **`无法判断`**：没有证据，且其他列也不能定论。**`evidence` 为空的淘汰行通常就是这一类**：
   凭引句观察不到“缺席”，我们宁愿要一个诚实的“无法判断”，也不要猜。

### `redefinition` —— 含义变了吗？

1. **`真漂移`**：引句显示同一概念的用法在定义、参与者或结构上发生了实质变化。
2. **`误报`**：引句的用法与原有含义一致，或说的其实是另一个概念。
3. **`无法判断`**：没有可比对的对照。

### 通用

- **不要凑比例**。本批误报远多于真漂移；逐行判断，总数该是多少就是多少。
- `无法判断` 是合法答案，不是没干活。用于证据为空或确实两读的情形，不要用于“我得去查语料”这种情形。
- 判的是这一行，不是这个系统。

## 四、示例（虚构，不在你的表里）

**A. `emergence`，引句三句讲“逆转录”是 RNA→DNA 的机制，并与文本中的普通范畴“DNA 复制”“转录”对照。**
→ `真漂移`，高。类型级机制，且被明确写成与普通机制不同。

**B. `emergence`，引句一句：“处理组该蛋白半衰期为 42 分钟”。**
→ `误报`，高。单个测量值，实例级。

**C. `emergence`，引句：“图 3 处理对表达的影响（n = 6）。”“裂解前洗细胞两次。”**
→ `误报`，高。题注与方法学套话，不指向任何类别。

**D. `emergence`，引句：“……与上文所述的早期观察一致。”（仅此一句，`n_members` = 1）**
→ `无法判断`，中。信息不足以归类。

**E. `extinction`，无证据，`n_members` = 0。**
→ `无法判断`，高——除非 `last_seen_t` 加概念名本身就足以支持该主张，那就在 `note` 里说明。

## 五、纪律

- **独立评**。在两位标注者的表都交回之前，不要与另一位、与作者、或在群里讨论任何一行。
  这次练习的价值就在于两份判断互相独立。
- **不要查资料**。只依据本表判断：不上网、不查原始语料、不读论文或代码仓库。这样你的表才与
  另一位可比；另外两个语料的使用条款也不允许再分发。
- **不要看别的文件**，特别是文件名里带 `llm` 或 `review` 的文件。如果你手上已有这类文件，
  请告知发件人并忽略它。
- **不要改动表结构**：不重排、不删行、不加列；只填 `label`、`confidence`、`note`。
  用表格软件请存回 CSV UTF-8，表头保持原样。
- **注意休息**。这类判断一小时后准确率会掉。两次各 45 分钟，好过一次 2.5 小时。

## 六、你的表会被怎么用

- 两份表按 `alarm_id` 合并，计算一致性（Krippendorff's α、Cohen's κ、阳性/阴性一致率，附
  bootstrap 区间）。
- 两人分歧的条目交第三人仲裁；你的 `note` **不会**交给仲裁人，避免措辞影响裁定。
- 结果以**匿名汇总统计**报告。除你要求匿名外，会在致谢中具名。论文中该部分写作
  “a limited human review of detected alarms”，不会写成对系统的验证。
- 请不要转发本数据包；交回并确认无误后删除副本。

## 七、交回方式

把同一份 CSV 交回，`label` 与 `confidence` 每行都要填，文件名不变（`rater_R2.csv` 或
`rater_R3.csv`）。实在拿不准的行也要给标签——`无法判断`——愿意的话在 `note` 里写一句原因。
